This repository contains the source code for the Fish Tool use project website (https://fishtooluse.com/). 
The project focuses on anvil use: a fish is using a hard surface to crack open hard-shelled prey. 

## Website pages

- **Home**: overview of what to look for, where to look, and example videos 
- **Tool use in animals**: background information on tool use in animals and fish
- **Project**: description of the research project
- **People**: project investigators 
- **Contact**: Contact page for reporting observations of fish using tools and data information (handling, consent, withdrawal, dataset plan and licence).
